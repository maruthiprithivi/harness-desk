# Changelog

## 0.1.0-beta.2 — Clearer setup and verification

- A visible first-project action and honest guidance before the first scan.
- Observed session totals alongside predicted sources, with missing capacity explained.
- Return to or cancel an active check after changing project or agent; prevent competing starts.
- Prioritize startup instructions and project changes over bundled or out-of-scope duplicates.
- Group large inventories by plugin provider before bounded ranges; keep known skill suites visible.
- Clear connection errors after recovery, identify form fields and provide a packaged favicon.
- Distinguish real-session validation from synthetic tests; record the successful Claude macOS check.
- Update GitHub installation guidance. Windows acceptance and per-category context attribution remain limited.
