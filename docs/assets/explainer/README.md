# Public explainer assets

The [video](harness-desk.mp4) is a 105-second narrated walkthrough of Harness Desk. Captions are burned into a reserved band below the full visual frame. A separate [WebVTT caption file](captions.vtt) is available for reuse.

The UI captures come from an isolated synthetic project. No real agent homes, repositories, configuration, transcripts or credentials were mounted in the screenshot fixture. The example 12,000 → 9,000 input-token comparison is simulated and does not establish real savings.

The poster is an extracted frame of the same reviewed video. Exact SHA-256 hashes for both binary assets are pinned in the public-source gate. A replacement requires a new visual and privacy review; arbitrary local media are not allowed.

See the [user guide](../../user-guide.md) and [Remotion source](../../../media/explainer/README.md). The application remains a development preview; support limits are described in the guide and the video.
