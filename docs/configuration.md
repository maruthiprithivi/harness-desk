# Understand and edit your setup

[README](../README.md) · [User guide](user-guide.md) · [Measurement limits](context-measurement-capabilities.md)

## Select a starting point

Choose an agent, repository and launch folder. Global guidance can affect many projects; project and folder guidance depend on where a session starts. A clean folder outside a repository differs from one inside it. Refresh discovery after external edits.

Alternate homes, managed policy, imports, launch flags and excluded sources can remain unresolved. The canvas predicts loading from supported rules; it does not inspect a live session.

## Follow the canvas

| Visual | Meaning |
| --- | --- |
| Global / project label | Source origin |
| Solid connection | Predicted instruction read order |
| Dashed connection | Ownership or availability |
| Category → family → file | Progressive expansion |
| Unknown / unresolved | Insufficient evidence |

Find sources in the left explorer. Select a node for an explanation or **Edit** for the resizable syntax editor. Pan, zoom, focus and hide affect the display only.

Codex selects one instruction candidate per directory and combines applicable guidance. Claude combines instruction text. Settings, skills and MCPs have separate rules; tree position alone does not establish every setting's precedence.

## Review skills and MCPs

Search, filter and sort the catalogue. Recorded calls, explicit Read requests and manual task notes are different evidence. Missing usage does not establish that a component is unused.

Inspect named MCP servers on demand. Static configuration can show transport, explicit enablement and inspection freshness; it cannot prove authentication, connection or prompt inclusion.

**Matching copies** identifies identical complete Markdown. Compare sources before deciding what to keep; a duplicate does not establish savings or which copy loads.

## Make one reviewed change

Confirm scope, edit, review the diff, then save and run a fresh representative check. Saving creates a private pinned backup. **Load latest backup** prepares a draft for review rather than silently overwriting a source. Stale, protected and unsupported writes are rejected.

Avoid simultaneous editing in another application. Portable filesystem checks cannot prevent every hostile concurrent directory replacement.

**Work on this** prepares a scoped agent request. Review context, choose the answering agent and explicitly send. Replies remain drafts; opening a chat does not change configuration.
