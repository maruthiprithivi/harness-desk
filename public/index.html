LOCAL DESCRIPTION MATCHES
Find skills for a task

    

      
Use ordinary words. This searches stored skill descriptions on this computer. It does not read skill bodies, change configuration or contact a provider.

      
Search details
Every eligible skill description in this repository and the selected agent's global setup is considered. Global scope considers global skills only. Shared skills are eligible. Matches rank by matching word count, then rarity of those words in descriptions, then stable source identity. Common filler is omitted and simple English plurals are normalized. Size does not determine the matches. This is word matching; it can miss suitable skills and does not verify fit or use.
